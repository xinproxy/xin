# Xin

Xin is a web server and reverse proxy that reads nginx configuration.

[Website](https://xin.dev) · [Downloads](https://xin.dev/releases/) · [Report an issue](https://github.com/xinproxy/xin/issues/new/choose)

## Install

Download a package or archive from the [download page](https://xin.dev/releases/), or use the [APT](https://apt.xinproxy.com/) and [RPM](https://rpm.xinproxy.com/) repositories. The [shell installer](https://install.xinproxy.com/) can select the appropriate package for your system.

Plain and FIPS builds are available where listed on the download page. Check `SHA256SUMS` and its signature with the [Xin archive signing key](https://dl.xinproxy.com/keys/xin-archive-keyring.asc) before installing an archive.

## Issues

Use [Issues](https://github.com/xinproxy/xin/issues) for bugs, compatibility problems, and feature requests. Please include the Xin version, operating system, architecture, relevant configuration, and steps to reproduce a bug. Remove passwords, private keys, tokens, and customer data before posting.
